
# Simple Port Scanner

A simple TCP port scanner built with Python.

## Features

- Validates IPv4 addresses.
- Scans the 100 most common TCP ports.
- Identifies open TCP ports.
- Displays common service names.
- Uses Nmap's services database.

## Requirements

- Python 3
- Nmap installed on Kali Linux

## Installation

Install Nmap:

```bash
sudo apt update
sudo apt install nmap
```

Clone or download this repository, then enter the project directory.

## Usage

Run the scanner:

```bash
python3 scanner.py
```

Enter the target IPv4 address when prompted.

## Disclaimer

Use this tool only on systems you own
or have explicit permission to test.
